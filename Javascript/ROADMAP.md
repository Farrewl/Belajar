# Roadmap Belajar JavaScript

> Bahasa web. Frontend + backend (Node.js).

## Level 1 — Dasar Sintaks
- [ ] `let`/`const`, tipe, template literal, `console.log`
- [ ] Operator, `if`, loop, `for...of`

## Level 2 — Struktur Data & Logika
- [ ] Array, object, Map/Set
- [ ] Function, arrow function, destructuring, spread

## Level 3 — Konsep Khas
- [ ] DOM manipulation, event listener
- [ ] Async: Promise, async/await, fetch
- [ ] OOP (class), module (`import/export`)

## Level 4 — Proyek Terapan
- [ ] CLI tool (Node.js)
- [ ] Mini web app (DOM + fetch)

## Menjalankan
```bash
node file.js
# di browser: buka index.html / Live Server
```
