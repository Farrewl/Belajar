# 05 — OOP & Modul (JavaScript)

## Konsep
`class`, constructor, method, inheritance (`extends`), `import/export`.

## Contoh
```js
export class Greeter {
  constructor(name) { this.name = name; }
  hello() { return `Halo ${this.name}`; }
}
```

## Latihan
1. Class `Todo` dengan method toggle.
2. Buat modul terpisah dan import.
3. Subclass dengan `extends`.
