# 03 — Struktur Data

## Konsep
Array statis 1D/2D, `struct` untuk satuan data berbobot, `enum`.

## Contoh
```c
typedef struct {
    char nama[50];
    int umur;
} Mahasiswa;

Mahasiswa m[3] = {{"Ani", 20}, ...};
```

## Latihan Mandiri
1. Simpan data 3 mahasiswa, tampilkan tabel.
2. Proses rata-rata nilai array 2D.
3. Hitung frekuensi elemen pada array.
