# Proyek 01 — CLI Tool (C)

## Spec
Buat CLI tool `greet` atau `counter` dengan argumen `argv`.

## Fitur
- Parse argumen string.
- Print output ke stdout.

## Ref Arsitektur
- https://github.com/anurseven/cli (C CLI example)
- https://github.com/iovisor/goblin (C syscall patterns)

## Tantangan
- Error handling untuk argumen tidak valid.
- Return exit code non-zero.
