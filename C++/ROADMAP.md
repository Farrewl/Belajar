# Roadmap Belajar C++

> Performance, abstraksi, sistem. Fondasi game engine & sistem besar.

## Level 1 — Dasar Sintaks
- [ ] `#include <iostream>`, `std::cout`, `cin`, tipe dasar
- [ ] `if/switch`, `for/while`, fungsi

## Level 2 — Struktur Data & Logika
- [ ] `std::vector`, `std::string`, `std::map`, `std::set`
- [ ] Reference, pointer dasar, overload fungsi

## Level 3 — Konsep Khas
- [ ] OOP: class, constructor, inheritance, virtual function
- [ ] RAII, smart pointer (`unique_ptr`, `shared_ptr`)
- [ ] Template & STL algorithm

## Level 4 — Proyek Terapan
- [ ] CLI tool (01-cli-tool)
- [ ] Mini game / konsol (02-mini-game)

## Menjalankan
```bash
g++ -std=c++17 main.cpp -o main && ./main
g++ -Wall -Wextra -std=c++17 main.cpp
```
