# 03 — Flexbox (HTML-CSS)

## Konsep
Display flex, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `order`, `flex-grow`, `flex-shrink`.

## Contoh
```css
.container { display: flex; }
.item { flex: 1; }
```

## Latihan
1. Layout horizontal 3 item sama lebar di dalam container flex.
2. Center vertikal & horizontal dengan `justify-content: center; align-items: center;`.
3. Urutkan item secara inverse dengan `flex-direction: row-reverse;`.
4. Item akan turun ke bawah (wrap) saat layar sempit.

Gunakan `<div class="container">` & `<div class="item">`.
