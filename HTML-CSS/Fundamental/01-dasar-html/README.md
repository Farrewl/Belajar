# 01 — Dasar HTML (HTML-CSS)

## Konsep
HTML skeleton, tag utama, struktur dokumen.

## Contoh
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Saya</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Ini paragraf.</p>
</body>
</html>
```

## Latihan
1. Buat dokumen HTML sederhana dengan judul & paragraf.
2. Tambahkan link menuju Google.
3. Tambahkan gambar di dalam body (gunakan URL remote saja, `src="https://..."`).
4. Buat form sederhana (name, email, submit).
5. Tabel 3 kol x 3 baris.

Jalankan: buka `index.html` di browser.
