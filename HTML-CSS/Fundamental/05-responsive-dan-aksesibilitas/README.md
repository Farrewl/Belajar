# 05 — Responsive & Aksesibilitas (HTML-CSS)

## Konsep
Media query `@media (max-width: 600px)`, `max-width`, `width: 100%`, `viewport` meta tag, `alt` text, semantic tags.

## Contoh
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
@media (max-width: 600px) { .container { flex-direction: column; } }
```

## Latihan
1. Lakukan viewport meta tag.
2. Buat grid 3 kol di desktop, 1 kol di mobile (media query).
3. Tambahkan `alt` deskriptif pada setiap gambar.
4. Gunakan semantic tag `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`.
5. Ganti warna teks agar kontras terhadap background.

Verifikasi dengan devtools.
