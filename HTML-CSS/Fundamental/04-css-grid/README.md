# 04 — CSS Grid (HTML-CSS)

## Konsep
`grid-template-columns`, `grid-template-rows`, `grid-gap`, `grid-area`, `grid-column`, `grid-row`.

## Contoh
```css
.container { display: grid; grid-template-columns: 100px 100px 100px; grid-gap: 10px; }
```

## Latihan
1. Grid 3 kol x 3 baris.
2. Grid 2 kol di layar lebar, 1 kol di layar sempit (media query).
3. Grid dengan area bernama (grid-template-areas).

Gunakan `display: grid`.
