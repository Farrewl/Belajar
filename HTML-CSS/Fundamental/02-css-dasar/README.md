# 02 — Dasar CSS (HTML-CSS)

## Konsep
Selector, properti warna, background, font-size, Box Model (width, height, margin, padding, border).

## Contoh
```html
<style>
    body { font-family: sans-serif; color: #333; }
    .box { width: 200px; height: 100px; background: #f0f0f0; margin: 10px; border: 1px solid #ccc; }
</style>
<div class="box"></div>
```

## Latihan
1. Tambahkan warna background ke body.
2. Buat div merah 100x100 px, margin 20px.
3. Ubah ukuran font paragraf menjadi 24px.
4. Buat container dengan border 2px solid & padding 10px.

Gunakan `style` inline maupun `<style>` di head.
