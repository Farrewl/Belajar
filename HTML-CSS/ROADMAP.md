# Roadmap HTML & CSS

> Modern web design fundamentals.

## Level 1 — Dasar HTML
- [ ] Struktur: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
- [ ] Tag text: `<h1..6>`, `<p>`, `<a>`, `<ul>`, `<li>`, `<em>`, `<strong>`, `<br>`, `<hr>`
- [ ] Image, link, table
- [ ] Form: `<input>`, `<button>`, `<label>`, `<select>`, `<textarea>` (est. 1 hari)

## Level 2 — Dasar CSS
- [ ] Selector: type, class, id, universal, descendant
- [ ] Properties: `color`, `background`, `font-size`, `text-align`
- [ ] Box model: `width`, `height`, `margin`, `padding`, `border`
- [ ] Color keywords, hex, rgb, rgba
- [ ] Flexbox layout (est. 1 hari)

## Level 3 — Konsep Khas
- [ ] CSS Grid: `grid-template-columns`, `grid-template-rows`, `grid-gap` (est. 1 hari)
- [ ] Responsive: media query `@media (max-width: 600px)` (est. 1 hari)
- [ ] Accessibility: `alt`, `aria-label`, semantic tags (est. 1 hari)

## Level 4 — Proyek Terapan
- [ ] Landing page (Projects/01-landing-page)
- [ ] Dashboard sederhana (Projects/02-dashboard)

## Menjalankan
- Open `index.html` di browser.
- Atau gunakannya Live Server (VS Code extension).
