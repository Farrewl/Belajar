# Roadmap Belajar Python

> Scripting, automation, data, AI. Bahasa paling ramah pemula.

## Level 1 — Dasar Sintaks
- [ ] Variabel, tipe data, f-string, input/output (est. 1 hari)
- [ ] Operator aritmatika, komparasi, logika

## Level 2 — Struktur Data & Logika
- [ ] List, tuple, dict, set, slicing
- [ ] if/elif/else, for, while, break/continue
- [ ] Fungsi, default arg, *args/**kwargs, lambda

## Level 3 — Konsep Khas (Pythonic)
- [ ] List/dict comprehension
- [ ] OOP: class, inheritance, dunder methods, dataclass
- [ ] Exception handling, context manager, generator
- [ ] Virtualenv, pip, packaging

## Level 4 — Proyek Terapan
- [ ] CLI tool (argparse)
- [ ] Data parser (CSV/JSON)

## Menjalankan
```bash
python3 file.py
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```
