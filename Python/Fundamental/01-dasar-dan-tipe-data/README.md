# 01 — Dasar & Tipe Data (Python)

## Konsep
Python dynamically typed. Tipe int, float, str, bool, None. f-string untuk formatting.

## Contoh
```python
nama = "Ani"
umur = 20
tinggi = 170.5
print(f"{nama} berumur {umur}, tinggi {tinggi:.1f} cm")
```

## Latihan
1. Input nama & umur, cetak salam.
2. Celsius -> Fahrenheit (cetak 2 desimal).
3. Hitung BMI dari tinggi & berat.
4. Cek tipe data dengan `type()`.
