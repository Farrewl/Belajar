# 02 — Control Flow & Fungsi (Python)

## Konsep
`if/elif/else`, `for`, `while`, `break/continue`, `def`, `return`, default argument.

## Contoh
```python
def kuadrat(x: int) -> int:
    return x * x

for i in range(1, 6):
    print(i, kuadrat(i))
```

## Latihan
1. FizzBuzz 1..100.
2. Fibonacci rekursif & iteratif.
3. Hitung nilai maksimum dari list tanpa `max()`.
4. Fungsi `is_palindrome(s)`.
