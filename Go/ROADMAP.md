# Roadmap Belajar Go

> Concurrency, backend, tooling. Bahasa infrastruktur modern.

## Level 1 — Dasar Sintaks
- [ ] `package main`, `import`, `func main`, `fmt.Println`

## Level 2 — Struktur Data & Logika
- [ ] slice, map, struct, method, interface

## Level 3 — Konsep Khas
- [ ] Goroutine & channel
- [ ] Error handling (`if err != nil`)

## Level 4 — Proyek Terapan
- [ ] CLI tool (01-cli-tool)
- [ ] HTTP service (02-http-service)

## Menjalankan
```bash
go mod init myapp
go run main.go
go build
go test
```
