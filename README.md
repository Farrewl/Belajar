## Cara Penggunaan
1. Pilih bahasa dari folder di atas.
2. Buka `ROADMAP.md` di tiap folder bahasa untuk panduan urutan belajar.
3. Kerjakan latihan di folder `Fundamental/` sesuai nomor urut.
4. Terapkan pengetahuan di folder `Projects/`.
5. Update file ini jika sudah menyelesaikan level tertentu.
