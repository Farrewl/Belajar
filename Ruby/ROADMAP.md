# Roadmap Belajar Ruby

> Produktivitas, web (Rails), scripting elegan.

## Level 1 — Dasar Sintaks
- [ ] Variabel, tipe, string interpolation, `puts`

## Level 2 — Struktur Data & Logika
- [ ] Array, Hash, symbol, block (`each`, `map`)

## Level 3 — Konsep Khas
- [ ] OOP: class, module, mixin, metaprogramming dasar
- [ ] Block, Proc, Lambda

## Level 4 — Proyek Terapan
- [ ] CLI tool (01-cli-tool)
- [ ] Mini web (02-mini-web, Sinatra)

## Menjalankan
```bash
ruby file.rb
bundle install
```
