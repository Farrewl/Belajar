# Roadmap Belajar Java

> OOP, JVM, enterprise. Fondasi kuat untuk Android/backend.

## Level 1 — Dasar Sintaks
- [ ] Tipe, variabel, operator, `System.out.println` (est. 1 hari)
- [ ] `if/switch`, `for`, `while` (est. 1 hari)

## Level 2 — Struktur Data & Logika
- [ ] Array, `String`, `ArrayList`, `HashMap`
- [ ] Method, parameter, return, overloading
- [ ] Exception try/catch (est. 1 hari)

## Level 3 — Konsep Khas: OOP
- [ ] Class, object, constructor, getter/setter
- [ ] Inheritance, abstract class, interface, polymorphism
- [ ] Generics, collection framework, Stream API

## Level 4 — Proyek Terapan
- [ ] CLI tool (01-cli-tool)
- [ ] REST console (02-rest-console)

## Menjalankan
```bash
javac Main.java && java Main
javac -d out src/*.java && java -cp out Main
```
