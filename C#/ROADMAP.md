# Roadmap Belajar C#

> .NET, OOP, desktop & game dev.

## Level 1 — Dasar Sintaks
- [ ] `var`, tipe, `Console.WriteLine`, `Console.ReadLine`

## Level 2 — Struktur Data & Logika
- [ ] Array, `List<T>`, `Dictionary<K,V>`, LINQ

## Level 3 — Konsep Khas
- [ ] Class, interface, abstract, generics
- [ ] Delegates, event, async/await

## Level 4 — Proyek Terapan
- [ ] Console tool (01-console-tool)
- [ ] Mini API (02-mini-api)

## Menjalankan
```bash
dotnet new console && dotnet run
csc Program.cs && mono Program.exe  # alternatif
```
